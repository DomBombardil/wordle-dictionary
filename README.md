# Wordle Dictionary Project

Wordle is a simple, terminal-based dictionary project written in Python.  
It serves as a lightweight practice project focused on program structure, user input handling, and data management.

The application starts by calling a **main menu function**, which presents all available actions and routes the user through the program.

This project is intentionally **bare-bones** and designed as a foundation rather than a finished product.

---

## Features
- Menu-driven interface
- Dictionary-based word storage
- Simple and readable program flow
- Easy to extend and refactor

---

## Purpose
This project was created as a **learning and experimentation tool** rather than a polished application.  
It demonstrates core Python concepts such as:
- functions and control flow
- working with data structures
- basic program architecture

---

## Planned Improvements
As a side project, this application will be expanded with:
- a more user-friendly interface
- improved input validation
- refactored internal structure
- a graphical user interface (GUI)
